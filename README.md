# PC Wake

スマホのホーム画面に追加できる、PC起動要求用のWebアプリです。ボタンから認証サーバーへ要求を保存し、Windows側のエージェントが**日本時間の毎時00分**に要求を確認します。ボタン操作から次の確認までは、通常最大約1時間です。

公開ページ: [PC Wake](https://wasuke5.github.io/pc-wake/)

API: [認証サーバー](https://pc-wake-hourly.wasuke-neko.chatgpt.site)

## 動作

1. スマホの「INITIATE WAKE / 次の00分に起動を予約」を押すと、サーバーが要求を保存します。
2. Windowsの復帰タイマーが毎時00分にスリープを解除し、エージェントが要求を確認します。
3. PCが要求を受信すると、30分間、自動スリープを抑止します。
4. 要求がなければ、自動復帰後はWindowsの電源設定に従って再びスリープします。

未受信の要求は24時間有効です。有効期限までにPCが受信しなかった場合は「要求の有効期限切れ」と表示します。

画面では「起動要求を保存済み」「PCが要求を受信」「PCオンライン」を区別します。オンライン表示には90秒以内のPCの応答が必要です。受付だけで起動成功とは表示しません。

宇宙のAIコンソールをイメージした画面に、動く星空、立体的なコア、軌道、送信中の光の演出を表示します。`NEXT SYNC`は次回確認時刻（日本時間）です。説明・ホーム画面への追加・登録変更は`SYSTEM`にまとめています。端末の「視差効果を減らす」設定に対応し、画面が非表示の間はアニメーションを停止します。

## PC側の条件

- Windowsにログインした状態で使います。画面をロックした状態でも動作します。
- AC電源に接続し、スリープと復帰タイマーを有効にします。
- 定期確認時にWi-Fiとインターネットへ接続できる必要があります。
- PCにエージェントと毎時00分のタスクを設定し、実際のスリープ解除を確認する必要があります。

この方式はスリープからの復帰用です。完全なシャットダウンや電源断からの起動には対応しません。Windowsが起きて要求を取りに行くため、ルーターの外部受信設定やLANケーブルは不要です。

## スマホに保存する

初回は、別途用意する**非公開の設定用リンクまたはQRコード**でスマホを登録します。設定用リンク、QRコード、登録コードはGitHubへ保存しません。公開ページだけを開いた場合は登録が必要です。

- iPhone: Safariで登録済みのページを開く → 共有 → ホーム画面に追加
- Android: Chromeで登録済みのページを開く → メニュー → ホーム画面に追加（またはアプリをインストール）

ホーム画面版で再登録を求められた場合は、非公開の設定用リンクか登録コードを一度だけ貼り付けてください。登録コードはスマホのブラウザーに保存されます。ホーム画面への追加操作はスマホ側で必要です。

PCへ接続して操作するには、起動後にリモート操作の接続手段を用意する必要があります。

## 構成

- `site/`: HTML、CSS、JavaScript、PWAマニフェスト、サービスワーカー、アイコン
- `.github/workflows/pages.yml`: `site/`だけをGitHub Pagesに公開
- 認証サーバー: 要求の保存、PCによる受信、状態取得
- Windowsエージェント: 毎時00分の確認とPCの応答送信

画面のビルドやnpmのインストールは不要です。`site/config.js`には公開APIのURLだけを設定します。登録コード、PC用の認証情報、GitHubトークンなどの秘密情報を公開ファイルへ入れないでください。API契約は[画面のREADME](site/README.md)を参照してください。
